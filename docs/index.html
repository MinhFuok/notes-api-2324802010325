Giới thiệu

Dự án minh họa môi trường phát triển trên đám mây bằng GitHub Codespaces, Node.js, Express và GitHub Pages.

API Hello Cloud cung cấp dữ liệu JSON qua HTTP, bao gồm thông tin máy chủ, CPU, RAM, hệ điều hành và thời gian hoạt động.

5 đặc tính điện toán đám mây theo NIST

1. On-demand self-service

Tự tạo và khởi chạy GitHub Codespace mà không cần nhân viên nhà cung cấp hỗ trợ.

Thực tế: Sinh viên tự cấp phát môi trường lập trình qua GitHub.

2. Broad network access

Tài nguyên Cloud có thể truy cập qua mạng bằng nhiều loại thiết bị.

Thực tế: Truy cập Hello Cloud API bằng điện thoại thông qua URL Public của Codespaces.

3. Resource pooling

Tài nguyên được cấp phát từ hạ tầng Cloud dùng chung của nhà cung cấp.

Thực tế: Sử dụng môi trường Codespaces với 2 CPU và 7.8 GB RAM theo API.

4. Rapid elasticity

Tài nguyên Cloud có khả năng mở rộng hoặc thu hẹp theo nhu cầu.

Thực tế: Codespaces hỗ trợ thay đổi cấu hình máy. Đã thực hiện khởi chạy và dừng Codespace, chưa kiểm thử co giãn tự động.

5. Measured service

Mức sử dụng tài nguyên được theo dõi, đo lường và thống kê.

Thực tế: GitHub Billing Usage ghi nhận 0.49 GB-month lưu trữ, chi phí trước ưu đãi $0.03, số tiền thực trả $0.
